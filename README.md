## 📌 About the Project

The **Recruitment Management System (RMS)** is a web-based application designed to organize and simplify the recruitment process.

The system provides recruitment personnel with a centralized platform for managing:

- Job postings
- Open positions
- Applicants
- Applications
- Applicant screening
- Interviews
- Hiring decisions
- Employees
- Recruitment reports
- Recruitment performance
- Recruitment pipeline

The system is designed to track applicants from their initial application all the way through screening, interviewing, selection, and hiring.
